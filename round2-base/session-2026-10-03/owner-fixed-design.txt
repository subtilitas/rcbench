2. THE FALLBACK, in effective_selection
- New parameter fixed=None, loaded from categories.json when None, so the self-test can pass its own.
- Inside the loop, collect the runs it actually read, which respects `before`.
- After the loop, for each category c and each fixed input x (function fn, table part T, orderable O):
  - e = eff[c].get(fn).
  - If e has a part that starts with T (case-insensitive, as isFixed does), keep e. A run verified it.
  - Otherwise set eff[c][fn] to: {part: O, rank: None, alternate: "", run: "owner", alternate_unverified: [], second_source_missing: False, q_alternatives: [], decision: e.decision or "none", q_options_missing: [], owner_fixed: {input: T, left_open_by: e.run or "", replaced: e.part or e.not_requalified or "", unverified: [...]}}.
  - unverified lists {run, part, status, reason} for each ledger row in summary.results[c].ledger whose function is fn, whose part contains T (case-insensitive), and whose status does not start with "verified".
  - "Contains" is needed because the pack's ledger part is the long product name. It picks up FU-2B1's refutation and FU-2F's "not verified" for the pack, and FU-2C's "refuted, no ruling" for ADXL316WBCSZ.
- An entry is also added when no run named the function.
- A pre-ruling run's verified non-matching part (for example a round 1 INA238AIDGSR) is replaced and named in `replaced`.
