# tools/check_sizes.py --check holds the tree to this list: a file over
# 1,000 code lines that is not here fails, and so does a listed file at or
# under 1,000 code lines.  A code line is a line that is not blank and not
# comment-only (see the tool's header for the rules per file kind).
# "figure +-tolerance" records a code-line count that is held; "none"
# records none.  A line count inside a reason (a section, a cut, a half) is
# a count of total lines as the reason was written, not of code lines.
# F<n> is a fork, "row <n>" a row, of the code size plan
# (rework/codesize-plan.md on branch rework/codesize).  Files generated by
# a tools/gen_*.py that CI runs with --check are the generator's to hold
# and are not listed.
#
# path | lines | reason
